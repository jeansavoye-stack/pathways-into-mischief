- OpenAI image generation — the original pyramid, maze and key icon.

The App Store save layout was compared with locally supplied test saves and the installed game’s behaviour. Historical offsets do not automatically apply to every release. This beta targets the format tested with port version 2.2.

No original game executable, resources, maps or personal test saves are included. Maps are loaded from the user’s installed copy of the game. The icon is an original illustration, not the game’s icon.
