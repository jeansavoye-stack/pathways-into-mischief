# Changelog

## 0.7.0-beta.1

First English distribution as **Pathways Into Mischief**.

- New name, English interface, About panel and credits.
- Universal Apple Silicon / Intel build.
- Health, inventory, category checkboxes, editable quantity menus and bundles.
- Original backups, restore, export, remembered files and folder access.
- Weapon proficiencies, clock controls and map-based teleportation.
- Self-contained synthetic backend tests, with no personal save fixtures.
- Original pyramid, maze and key application icon.

Gameplay validation began with private French prototypes. This first public candidate remains experimental, especially for the Colt, extreme values, event timing and unusual inventory combinations.
