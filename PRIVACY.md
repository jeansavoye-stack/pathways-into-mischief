# Privacy

The application has no telemetry, account, analytics or upload feature, and makes no network requests in its implementation.

Save editing and tests run locally. The application remembers the selected file, folder-access bookmarks and original-backup locations in its macOS preferences. Backups are created alongside the selected file. Runtime map viewing reads the Maps file inside the separately installed game.

A save file may contain player names and progress. Do not attach one to a public issue unless you want that data to become public. Start bug reports with the application version, game version, macOS version and reproduction steps.
